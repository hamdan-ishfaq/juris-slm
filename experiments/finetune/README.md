# Fine-tuning experiments

Earlier work on fine-tuning a Phi-3.5 model for legal questions. **It is not part of the product.**
JurisGuard runs a stock model through Ollama, and nothing in `backend/` imports this folder.

Kept for reference. None of it has been re-run since the repository was reorganised, and no results
from it are claimed anywhere.

Run the scripts from the repo root, for example `python experiments/finetune/02_prepare_training_data.py`.
Install their dependencies from `requirements-finetune.txt`.
